## 6. 长期规划（Phase 5+）

- **多用户支持**：家人 / 朋友各自的数据
- **云同步（可选）**：iCloud 同步进度
- **iPad / iPhone 扩展**：Tauri iOS（beta） / React Native
- **更多题库**：剑桥 19+、雅思 OG
- **G 类  移民类雅思支持**
- **AI 老师对话**：基于历史弱项的个性化练习

## 7. 不要做的事（防止 scope creep）

- ❌ 社交功能（评论 / 分享）
- ❌ 付费 / 会员系统
- ❌ 复杂的学习日历 / 提醒系统
- ❌ 错题本（macOS Notes 够用）
- ❌ AI 生成范文 / 录音（必须真实数据）
- ❌ 多端同步（M1 暂不做）

## 8. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 爬虫被反爬 | 数据采集失败 | 限速、备选源、人工补充 |
| Whisper API 成本高 | 费用超支 | 限制每月转写次数 / 用本地 whisper.cpp |
| AI 评分不准 | 用户信任度低 | Few-shot 优化 + 一致性测试 |
| Tauri 打包问题 | 无法发布 | 预留 Web 原型作为 fallback |
| 用户数据丢失 | 不可恢复 | 自动备份 + 导出功能 |
