# 01 · 产品需求文档（PRD）

## 1. 项目概述

### 1.1 一句话定义
为家庭用户打造的 macOS 雅思备考桌面应用，提供真题题库、真实高分样本学习和 AI 评估反馈。

### 1.2 目标用户
- **主要用户**：陈泽华（踹妈），在职小学英语老师，备考雅思
- **典型场景**：
  - 周中晚上：刷真题 + 学习范文（30-60 分钟）
  - 周末上午：限时写作练习（40 分钟/篇）
  - 任意时间：录音练习口语
- **使用设备**：macOS 笔记本（主）、可能扩展到 iPad

### 1.3 核心价值主张
1. **真实数据**：所有范文和口语录音来自公开渠道，非 AI 生成
2. **AI 评估闭环**：写完 / 录完立即得到专业反馈
3. **本地优先**：离线可用，数据本地存储，隐私安全

## 2. 功能需求

### 2.1 写作模块

#### 2.1.1 真题题库（M1 - 必须）

**功能描述**：
- 浏览近 10 年雅思写作真题
- 按剑桥 IELTS 10-18（36 道 Task 2）组织
- 按题型（观点/讨论/利弊/问题解决）、话题、难度筛选
- 关键词搜索

**数据要求**：
- 题库来源：
  - 剑桥 IELTS 10-18 官方真题（公开出版物）
  - 雅思哥公开题库（ieltsbro.com）
  - 其他公开来源（学员回忆版）
- 每道题字段：`book`、`test`、`examDate`、`task(1|2)`、`prompt`、`type`、`tags[]`、`difficulty`、`essayCount`

**UI 要求**：
- 列表展示，每行展示：题型 tag、话题 tag、考试日期、配套范文数
- 顶部筛选栏：Task 1/2、题型 chips、搜索框
- 点击进入题目详情页

#### 2.1.2 范文学习（M1 - 必须）

**功能描述**：
- 每道真题配套多篇真实高分范文
- 范文筛选阈值：**8 分及以上**
- 每个范文包含：分数、来源出处、字数、用时、完整正文
- 配套解析：结构分析、逻辑分析、高分词汇标注、"为什么得高分"要点

**数据要求**：
- 范文来源（爬虫目标）：
  - **IELTS Liz**（ieltsliz.com）—— 题型全、有范文
  - **IELTS-Simon**（ielts-simon.com）—— 前雅思考官，范文质量极高
  - **DC IELTS**（dc-ielts.com）—— 范文库
  - **雅思哥高分范文区**
  - **新浪/腾讯教育频道** —— 老题整理
- 每个范文字段：`topicId`、`score(≥8)`、`author`、`source`、`wordCount`、`timeSpent`、`content`、`analysis{structure,logic,vocabHighlights[],whyHighScore[],bandCriteria{taskResponse,coherence,lexical,grammar}}`
- **必须标注来源出处**（个人学习用但仍要尊重原创）

**UI 要求**：
- 题目详情页：范文 tabs 切换
- 左侧：范文正文（衬线字体、阅读友好）
- 右侧：四项评分条形图、"为什么得高分"列表、高分词汇 tag 集合

#### 2.1.3 AI 作文评估（M1 - 必须）

**功能描述**：
- 用户提交自己的作文
- AI 按雅思四项评分标准（Task Response / Coherence & Cohesion / Lexical Resource / Grammatical Range & Accuracy）评分
- 输出：总分、四项分、详细反馈（优点/改进点/错误）、词汇升级建议、结构建议

**技术要求**：
- 评分模型：`minimax/MiniMax-M3`（默认，可替换为 Claude/GPT-4o）
- 评分 prompt：详见 `04-ai-evaluation.md`
- 评估时间：≤ 5 秒
- 评估结果持久化（SQLite 本地数据库）

**UI 要求**：
- 左：题目选择 + 作文输入框（带字数统计）
- 右：评估结果（总分圆环 + 四项分条形图 + 反馈清单 + 词汇升级 + 结构建议）

### 2.2 口语模块

#### 2.2.1 优秀口语录音库（M2 - 次要但重要）

**功能描述**：
- 收录公开渠道的高分（8-9 分）雅思口语示范
- 每个录音包含：音频播放器、完整转写文本、AI 多维度分析
- AI 分析维度：流利度 / 词汇 / 语法 / 发音 / 内容组织，每个维度的亮点 + 改进空间

**数据要求**：
- 录音来源（爬虫目标）：
  - YouTube：
    - IELTS Liz（50 万粉）
    - E2 IELTS  - IELTS Energy Podcast
    - Magoosh IELTS
    - Oxford Online English
  - B站：搜索"雅思口语 8分示范"、"雅思口语 9分"
  - British Council 官方示范视频（查证许可）
- 转写：Whisper API 或本地 whisper.cpp
- 每个录音字段：`part(1|2|3)`、`topic`、`prompt`、`source`、`score(≥8)`、`duration`、`transcript`、`analysis{fluencyHighlights[],lexicalHighlights[],grammarHighlights[],pronunciationHighlights[],contentHighlights[],sentences[{text,translation,technique}],improvements[],bandCriteria{fluency,lexical,grammar,pronunciation}}`

**UI 要求**：
- 左侧：录音列表（按 Part 筛选）
- 右侧：详情页（音频播放器 + AI 分析 tab + 转写 tab）
- AI 分析：总评 + 四项评分 + 五维亮点 + 高分句型 + 改进空间

#### 2.2.2 口语录音练习 + AI 评估（M2 - 次要）

**功能描述**：
- 用户录音回答题目
- AI 评估：发音准确度、流利度、词汇、语法、内容相关性
- 输出：四项分、转写文本（标黄冗余词）、维度反馈

**技术要求**：
- 录音：浏览器 MediaRecorder API（Web 原型） / Tauri 的麦克风权限
- 转写：Whisper API
- 评估：基于转写文本 + 音频特征，调用 LLM 评分

**UI 要求**：
- 录音按钮（动画效果：未录/录制中/分析中）
- 转写文本（高亮 um/er 等冗余词）
- 评分结果（与优秀录音同样的五维分析）

### 2.3 辅助模块

#### 2.3.1 学习看板（M3 - 可选）

- 总练习数、平均分、弱项分布
- 简单图表即可，不需要复杂统计

#### 2.3.2 错题本（暂不做）
#### 2.3.3 学习日历（暂不做，macOS 系统日历已够用）

## 3. 非功能需求

### 3.1 性能
- 页面加载：≤ 2 秒
- AI 评估响应：≤ 5 秒
- 录音/播放：无明显延迟

### 3.2 隐私
- 所有用户数据（作文、录音、评分记录）本地存储
- 不上传到云端（除非用户主动启用云同步）
- 评分调用 AI API 时不上传用户身份信息

### 3.3 离线
- MVP 必须支持离线浏览（题库、范文）
- AI 评估需要联网（提示用户）

### 3.4 macOS 原生体验
- 标题栏红绿灯按钮
- 系统字体（SF Pro Display / PingFang SC）
- 圆角、阴影、毛玻璃背景
- 通知中心集成（学习提醒）
- Dock 栏图标

## 4. 验收标准（M1）

### 4.1 功能验收
- [ ] 能浏览 36 道剑桥 IELTS 10-18 Task 2 真题
- [ ] 每道题至少配 2 篇 ≥ 8 分真实范文，标注来源
- [ ] 用户提交作文后能拿到 AI 四项评分 + 改进建议
- [ ] 数据本地持久化（重启后历史记录保留）

### 4.2 UI 验收
- [ ] macOS 原生视觉风格（参考 prototype/）
- [ ] 所有页面响应流畅，无明显卡顿
- [ ] 暗色 / 亮色模式自适应

### 4.3 工程验收
- [ ] TypeScript 严格模式，零类型错误
- [ ] 关键功能有单元测试
- [ ] README 完整，能一键启动

## 5. 不做什么

明确列出不做的事情，避免 scope creep：
- ❌ 不做社交功能（评论、分享）
- ❌ 不做付费 / 会员系统
- ❌ 不做云同步（用户量少，本地够用）
- ❌ 不做移动端（iOS/iPad 后续考虑）
- ❌ 不做错题本（macOS Notes 已够）
- ❌ 不做学习日历（macOS Calendar 已够）
- ❌ 不做 AI 生成内容（所有范文 / 录音都是真实公开数据）
